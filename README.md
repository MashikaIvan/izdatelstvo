
# Izdatelstvo
Лабораторная работа на тему "Создание веб-приложения для книжного издательства"
<!--Запуск-->
## Запуск
<!---->
1. Загрузка (клонирование) репозитория

```git clone https://github.com/MashikaIvan/izdatelstvo```

2. Запуск приложения
<!---->
В папке Izdatelstvo переходим в папку Izdatelstvo, затем в bin, затем в Debug, после этого открываете Izdatelstvo.exe.
Полный путь должен вышлядеть вот так:
```[Путь до папки с проектом]\Izdatelstvo\Izdatelstvo\bin\Debug\Izdatelstvo.exe```
